# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A Unity 6 project (editor `6000.3.23f1`, see `ProjectSettings/ProjectVersion.txt`) used to study shader writing. It uses the built-in render pipeline (no URP/HDRP packages in `Packages/manifest.json`), with the Post Processing Stack v1 profile in `Assets/PostProcessing`.

There is no CLI build, lint, or test setup. Work happens in the Unity Editor: open the project, then open `Assets/Scenes/MainForShaderSession.unity` (the only scene) and use Play mode to check changes. The `*.csproj` and `.sln` files at the root are generated by Unity and should not be edited.

## Layout

- `Assets/Shaders`: custom shaders. `InvisibleShader.shader` is an Amplify Shader Editor export (a CG surface shader that grabs the screen with `GrabPass` and distorts it with a normal map). Prefer editing it by hand only if you accept that re-exporting from Amplify will overwrite changes.
- `Assets/Materials`: materials for the maze and character models. Shader properties set from scripts must match the property names in the shader.
- `Assets/Scripts`: small MonoBehaviours. `PatrolAgent` drives a `NavMeshAgent` through a `waypoints` array. `HoloManGlitcher` toggles material properties (`_Amount`, `_CutoutThresh`, `_Amplitude`) on a timer, so it depends on a hologram shader exposing those properties.
- `Assets/Standard Assets`: Unity's legacy Standard Assets (characters, cross-platform input, utilities). Treat as third-party.
- `Assets/Models`, `Assets/Textures`, `Assets/Animation`: FBX meshes, textures, and the turntable animation.

## Conventions

- Every asset has a `.meta` file with its GUID. Commit them together, and move or rename assets inside the Unity Editor (or move the `.meta` too) so references in scenes and materials do not break.
- `Library/`, `Temp/`, `Logs/`, and `UserSettings/` are generated and should stay out of version control.
